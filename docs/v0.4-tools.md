# v0.4 Tool仕様: FlattenRectangle / FlattenPath / CreateWalkablePath

v0.4で追加した3 Toolの入力、高度profile、計画、結果（Terrain Operation Result）の定義です。本実行（`bDryRun=false`）の検証手順、retry、診断、制限は [v0.4 Apply contract](v0.4-apply.md) にあります。

## API

公式ToolsetRegistryがUFUNCTIONから生成するschemaを使用します。成功時は`returnValue`に`FLandscapeMCPTerrainOperationResult`を返します。既存10 Toolのsignature/Result型を変更しません。

共通: 距離・座標はWorld cm、高さは絶対World Z cm、角度は度。全数値finite。座標と明示高度は±10000000cm。完全な読み込み済みActor Object Pathを指定し、名前検索・暗黙Asset loadは行いません。

| Tool | required input | optional input / default |
|---|---|---|
| FlattenPath | landscapePath:string、points:array of {x:number,y:number}、widthCm:number、falloffCm:number、heightMode:string、targetHeightCm:number、maxDeltaCm:number | bDryRun:boolean=true |
| FlattenRectangle | landscapePath:string、center:{x:number,y:number}、sizeXCm:number、sizeYCm:number、targetHeightCm:number、falloffCm:number、maxDeltaCm:number | yawDegrees:number=0、bDryRun:boolean=true |
| CreateWalkablePath | landscapePath:string、points:array of {x:number,y:number}、widthCm:number、falloffCm:number、maxSlopeDegrees:number、maxDeltaCm:number | bDryRun:boolean=true |

公式generatorは通常の引数defaultをschemaへ反映します。条件付きschemaは導入せず、FlattenPath.targetHeightCmは常にrequiredです。fixedでのみ使用し、non-fixedではfinite・座標範囲内の値を受け取って使用しません。呼び出し側はnon-fixedで0を指定してください。profileHeightsCmとprofileSampleIntervalCmは公開しません。

widthCmはcoreの全幅、sizeXCm/sizeYCmは軸平行矩形coreの全長。falloffCmはcoreの外側へ追加する距離で、既存円Toolのfalloff割合とは別です。width/sizeは(0,5000]、falloffは[0,2500]、maxDeltaは(0,1000]、maxSlopeは(0,60]。yawは0だけを受理し、360等を正規化しません。

`bDryRun=true`（既定）は計画だけを行い、Landscapeへ書き込みません。`bDryRun=false`は検証を通った場合だけ書き込みます。Applyの手順は [v0.4 Apply contract](v0.4-apply.md) を参照してください。既存Toolの編集能力は変更していません。

## Height profile

- fixed: targetHeightCmの定数profile。
- follow_start: snapshotの始点XYを、既存GetHeightと同じbilinear補間で読み、定数profileへ。
- follow_path: snapshotの**各入力knot**をbilinear補間で読み、XY弧長に沿ってknot高度を線形補間。station間にある元地形の凹凸をそのままprofileへ転写するものではありません。明示Z profileはscope外です。

samplingの内部上限間隔は`min(100,Scale.X,Scale.Y)`cm。各segmentを`ceil(segmentLength/interval)`分割し、全knotと終点を保持します。1024点に収めるための粗化はしません。OutputのprofileSamplingIntervalCmは**実際のstation間隔の最大値**です。segmentごとの短い間隔も配列から確認できます。

coreはround cap付きPolyline帯。segment最近点のprofile高度を、隣接segment影響帯では`max(0,1-(distance/outerRadius)^2)^2`の正規化加重平均でblendします。join付近ではtarget profileと実現planned heightが異なるため、Outputに両方を返します。C0連続性を意図し、道路の厳密な縦断再現や曲率連続性を保証しません。

degenerate segment（長さ1cm未満）、自己交差、非隣接外側帯の重なり、U-turn/直角以上の折れは拒否します。幅に対して元格子の支持が不足する要求も拒否し、自動で幅を広げません。stationを含むセルの4頂点がcore内にあることを保守的に要求するため、小さい幅や端部で受理範囲が狭くなることがあります。

矩形の外側falloffは矩形までのEuclidean distanceでround cornerを作ります。core内はweight1、外側はsmoothstep、外縁は0。falloff0では硬い境界になります。

## Walkable planner

現在station高度の±maxDeltaと表現可能高度範囲からfeasible intervalを作り、端点高度は現在値へ固定します。前向き・後向き伝搬で縦断勾配条件を満たす区間へ絞り、始点からcurrent高度に最も近い値を決定的に選びます。profileはpiecewise linearです。

計画用angleは`maxSlopeDegrees - 2*atan(TriangleGradientError(q,Scale.X,Scale.Y))`（度）として量子化誤差分の余裕を取ります。angleが正でない場合も拒否します。この余裕だけで安全とはみなさず、join/falloff適用後にuint16 encode/decodeしてnative triangleを再評価します。

core interiorとtriangle interiorにpositive-area intersectionがある**全三角形**を評価します。edge/corner touchだけはcore対象に含めません。Rectangleはgrid正規化polygon clipping、Pathはtriangleと有限線分の最小距離対core半径で判定します。grid scaleとWorld座標の浮動小数点精度を踏まえたepsilon内の微小な重なりは`AMBIGUOUS_CORE_INTERSECTION`で拒否します。

成功にはwalkableRatio=1、nearLimitCount=0、unwalkableCount=0が必要です。分類・uncertainty・00-11 splitは既存TerrainAnalysisを再利用します。transitionはcore外でaffected頂点に接する三角形を集計し、各planned slopeがmax(current slope,要求maxSlope)を超える場合に拒否します。端点の実現高度も現在高度±q/2以内である必要があります。

必要条件を満たしても最終native triangle検証で拒否する場合があります。false negativeを許容し、自動retry/optimization loopや経路探索は行いません。source geometryの計画を確認するToolで、Collision/Character/NavMesh通行の保証ではありません。

## Result

全fieldを返します。未算出値はvalid=falseと数値0/空配列で表し、無効な0を測定結果とみなさないでください。新しいResult型だけを使用し、既存Resultにfieldを追加しません。

| field group | 意味 |
|---|---|
| schemaVersion、bSuccess、bDryRun、status、operation、landscapePath、message、errorCode | schemaVersion1。Dry-run成功はPREVIEW_READY/NO_CHANGE、Apply成功はAPPLIED/NO_CHANGE。拒否はREJECTED、書き込み後の失敗はROLLED_BACK/ROLLBACK_FAILED |
| requestedBounds、affectedBounds、readBounds、verificationBounds | XY bounds＋bValid。要求core+falloff、実候補頂点、snapshot＋halo、core/transition評価頂点の外接矩形 |
| requestedSampleCount / affectedSampleCount / readSampleCount | 未clip shape内候補、Landscape内候補、halo込みsnapshot読取数 |
| plannedModifiedCount / modifiedCount | uint16で変化する計画数／実変更数。modifiedCountはApply成功時だけ0以外 |
| clippedSampleCount / bClipped | requested−affected／幾何clip。lost vertex0でもbClippedの場合あり |
| before / plannedAfter / actualAfter | height stats＋native triangle slope/uncertainty/分類。actualはApply成功時だけ有効 |
| transitionBefore / transitionPlannedAfter / transitionActualAfter | core外の三角形集計。actualはApply成功時だけ有効 |
| delta | 候補頂点全体のquantized min/max差、maxRaise=max(0,maxΔ)、maxLower=max(0,−minΔ) |
| heightQuantizationCm | Scale.Z/128 |
| bPlanValid / bActualValid / bWalkabilityGuaranteed | 完全plan確認／実地形確認（Apply成功時だけtrue）／WalkablePathのcore source geometry計画保証 |
| path | length/width/falloff/実station最大間隔/countとprofileSamples。矩形はinvalid/空 |
| warnings / unsupportedReasons / rollbackStatus | 警告と拒否理由。rollbackStatusはNOT_NEEDED／VERIFIED／FAILED |

height statsの母集団はaffected候補頂点で共通です。triangle statsはcoreまたはtransitionの各maskです。flatten系にはcaller slope閾値がないため、bWalkabilityValid=false、比率/分類数は0にし、slopeだけを返します。walkability評価角を暗黙選択しません。

profileSamplesはdistanceCm/worldX/worldY/currentHeightCm/targetHeightCm/plannedHeightCmを持ちます。current/plannedは同じbilinear補間、targetは縦断profileです。

失敗は既存Toolと同じくRaiseScriptErrorからMCPの`isError`へ渡します。boundedなJSON診断（errorCode / operation / stage / landscapePath / reason / mutationDisabled / message / rollbackStatus）を含み、失敗時に正常な`returnValue`が届くとは約束しません。診断の詳細は [v0.4 Apply contract](v0.4-apply.md) を参照してください。

## Limits / safety

| 項目 | 上限 |
|---|---|
| path points / XY length | 64 / 10000cm |
| core width / rectangle sides / falloff | 5000cm / 各5000cm / 2500cm |
| requested vertices / unclipped AABB candidates | 16384 / 65536 |
| read vertices（1セルhalo含む） | 16384 |
| profile samples | 1024 |
| cached source mip bytes | 32MiB。Texture metadataでcopy前に判定 |

snapshotは元mipのコピーであり、通常のFLandscapeEditDataInterface読み取りを使用しません。読み取り上限にはmip全copyのbyte budgetも含めます。既存Readerはdefaultで従来の制限を維持し、32MiB制限を新規bridgeだけへ指定します。全support/haloがないsnapshotをplanへ渡した場合は拒否します。

既存ResolveのWorld Partition/Proxy/Layer/rotation/Nanite/hole/attached Foliage/shared texture等の安全境界を維持します。flattenの縁clipは明示報告、Walkable core clipは拒否します。Apply専用の安全条件、Transaction／Undo／rollback／latch、collisionの検証は [v0.4 Apply contract](v0.4-apply.md) にあります。
