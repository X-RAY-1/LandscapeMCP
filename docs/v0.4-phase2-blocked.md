# v0.4 Phase 2 — BLOCKED

Production `bDryRun=false` for the three v0.4 tools is disabled with
`PHASE2_BLOCKED_COLLISION_VERIFICATION`. DryRun continues through the unchanged
Phase 1 preview path. Existing ten tools are unchanged.

The uncommitted Apply implementation is a review draft. Only an explicitly
scoped Automation fixture can exercise it; there is no reflected function,
console command, config setting or MCP recovery/failure toggle.

## Blocking evidence

A native single-slope fixture (`height = 25cm * gridX`, grid spacing 100cm)
fails the source-to-collision normal comparison before any v0.4 write:

| Measurement | Value |
|---|---:|
| Source triangle centroid height | 641.666666667cm |
| Collision trace height | 641.655985351cm |
| Source/collision normal distance | 0.000172330 |
| Current normal comparison tolerance | 0.000100000 |

Shortening the trace ray did not change the measured discrepancy. Chaos
re-encodes the native source into another uint16 heightfield, using its own
min/max range and truncation. For this fixture the additional step is
`1575 / 65535 = 0.0240329594873cm`. Applying that codec independently predicts
the measured collision height and normal difference. This is not evidence of
an asynchronous update that a longer wait would fix.

No tolerance was widened and the fixture was not removed. A codec-aware
verification contract, including repeated edits, Undo/Redo, rollback and
walkability uncertainty, is still required. The draft is not accepted as a
safe, completed Apply implementation.

## Retained draft

- Prepared quantized buffers and geometry masks from Phase 1 planning.
- Immediate target identity/source/collateral revalidation.
- One transaction with a unique context, title and actual UE transaction GUID.
- Full read rectangle and halo verification; actual geometry recalculation.
- Collision line traces of both native triangles in every selected cell.
- Owned-latest-transaction checks before rollback; fresh restore verification.
- Module-session mutation latch on unverifiable restoration.
- Conservative grass/foliage guards and retry history without eviction.
- A narrow draft save policy: autosave/automatic checkout disabled and source
  control provider inactive. The tool never changes those Editor settings.

The prior isolated Safety build passed the three representative Apply cases,
retry NO_CHANGE, source Undo/Redo, A–J fault scenarios, grass/foliage guards and
No Save/No Collateral checks. It failed the single-slope collision fixture.
Those results describe that draft build, not production readiness.

The HTTP MCP attempt verified DryRun, Apply, retry and preserved error JSON,
but its external client did not accept the pretty-printed diagnostic and the
latent harness timed out. The parser is corrected; the remaining Apply MCP
round trips were not rerun after the STOP condition. See the external A–M
report and raw reports for the exact tested versions and incomplete checks.

No commit, push, tag, release or README update was made.
