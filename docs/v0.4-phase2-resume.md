## Apply and restoration contract

Expected collision is independently predicted from fresh Source using the Chaos codec and complete per-component min/max. It is never inferred from actual packed Chaos values or measured traces. Planned codec geometry and walkability are checked before the immediate pre-write identity, Source, collateral and safety revalidation. One owned transaction writes the quantized Source. Fresh Source, geometry, collateral and actual collision must pass before success.

Rollback requires ownership proof for the latest transaction, successful Undo, exact original Source plus halo, valid identities, original codec prediction, actual restored collision and unchanged collateral. Unprovable restoration latches v0.4 mutation off for the module session. All A-J fault cases were rerun on final Source. No public recovery API exists.

CreateWalkablePath requires positive combined safety margin for Source and predicted collision, actual collision verification, walkableRatio=1, nearLimitCount=0 and unwalkableCount=0. Flat zero-range collision is accepted by decoded geometry; packed uint16 bit portability is not guaranteed.

## Scope and remaining limitations

Apply keeps conservative guards: an idle Editor transaction buffer, supported single loaded Landscape/edit layer/native mip0 collision, inspectable Engine default material with no unsafe Grass/Foliage state, autosave and automatic checkout disabled, and inactive source control provider. Tools do not change Editor settings or save assets. Package dirty state is permitted for Apply.

Retry history (amended): a module-local idempotency cache bounded to 128 records with oldest-first eviction. A matching request whose recorded result still equals the current Source and target identity returns NO_CHANGE without another transaction or write. A record that no longer matches is discarded and the request is planned and verified from fresh state; STALE_RETRY_STATE and RETRY_HISTORY_CAPACITY_EXCEEDED no longer exist. Restart/module reload idempotency is not guaranteed.

Collision component metadata reads cover the complete component domain beyond the frozen request-plus-halo limit of 16384 samples. Landscape-size limits and the 32MiB Source cache bound this scan. Verification does not thin samples, native triangles or traces.

Final maximum measured Apply was 107.217ms internally / 107.226ms external fixture time; large mask verified 29766 native triangles. Timings depend on CPU/Editor load and do not guarantee a latency upper bound. SetHeightData and EditData.Flush share one timing interval; derived update is measured separately.
